# Classic Era macro index

Parked notes only. ShadowUI does not load, inject, or bind these macros.

Scope: **Classic Era** (client 1.13+ conditionals). Season of Discovery (SoD) extras sit in a short note at the end of each class file. TBC / Wrath / Retail syntax is out of scope.

Copy a block into a Blizzard character or account macro. Stay under **255 characters**. Put the macro on an Action Slot. Keybinds stay on the ShadowUI button (Base → Class → Variant).

## Playstyle groups (all classes)

Use this as the checklist when you build a bar. Each class file fills the rows that apply.

1. **Start combat** — Charge, opener, Hunter's Mark, pull spell.
2. **Main damage** — the button you press every GCD, with `/startattack` on melee.
3. **Rage / energy / mana dump** — Heroic Strike, Cleave, Arcane Shot rank 1, Life Tap, downrank filler.
4. **Interrupt** — `/stopcasting` then Kick / Pummel / Shield Bash / Counterspell / Earth Shock / Spell Lock / Bash.
5. **Crowd control** — Polymorph, Sap, Hibernate, Shackle, Banish, Fear.
6. **Defensive** — Shield Wall, Evasion, Ice Block, Fade, Feign Death, bubble.
7. **Help on target** — heal, dispel, Blessing, Innervate, BoP on the current target.
8. **Self modifier** — Alt-self heal or buff without losing target.
9. **Stance / form / aura** — one key that swaps stance then casts.
10. **Downrank** — same button: Shift cheap rank, Ctrl Rank 1 when needed, no modifier max rank.
11. **Pet** — attack, follow, passive, Spell Lock, Sacrifice.
12. **Travel** — teleport vs portal, Ghost Wolf, Travel Form, mount.

## Faction locks (Classic Era)

- Paladin is Alliance only. Shaman is Horde only.
- Mage portals and teleports: Alliance cities Stormwind, Ironforge, Darnassus. Horde cities Orgrimmar, Undercity, Thunder Bluff.
- Priest racials differ. See [priest.md](priest.md).

SoD can unlock the other faction class. Spell names in these files stay Era names unless a SoD note says otherwise.
