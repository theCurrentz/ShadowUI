# Loadout Snapshots are gone

ShadowUI no longer copies live Action Slots between Characters. Macro Cursor writes the Action Deck overlay. Loadout Snapshots needed in-game pickup and place, lived beside Profiles, and added a second copy path. Forever keeps one Account Profile for Layout, Keybinds, and the Action Deck. ShadowUI does not PlaceAction in-game.

Status: accepted. Supersedes [ADR 0005](0005-in-game-loadout-snapshots.md).
