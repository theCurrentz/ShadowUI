# Account-owned class inheritance instead of character profiles

Most bar addons store layout per character (AceDB profiles). ShadowUI stores Layout and Keybinds on the Account and merges Base → Class → Variant. A Character only records the active Variant, Manual Override, edit Layer, and Action Slot hard lock. Those are not Layout.

New characters of the same class get a complete layout with no wizard. An edit on the Class or Variant layer is visible to every same-class alt. Per-character profiles would leave alts empty. One global layout with no Class or Variant would not cover stance bars or talent-tree binds.
