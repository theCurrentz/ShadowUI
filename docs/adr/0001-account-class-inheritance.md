# Account-owned class inheritance instead of character profiles

Most bar addons store layout per character (AceDB profiles). ShadowUI stores Layout and Keybind overlays on the Account and merges Base → Class → Variant, then a sparse Character overlay. Character is not a full profile: same-class alts still inherit Account Class and Variant with no wizard.

An edit on the Class or Variant layer is visible to every same-class alt. Character deltas apply last and stay on that toon. One global layout with no Class or Variant would not cover stance bars or talent-tree binds. A Bartender-style per-character profile would leave alts empty.
