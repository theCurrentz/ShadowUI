# Frame Art

Classic `Interface/TargetingFrame/UI-TargetingFrame` (256×128).

ShadowUI paints the TGA in this folder instead of the Blizzard file. The border keeps its outer shadow. The inner shadow inside the health and mana wells is removed. Elite, rare, rare-elite, minus, and no-level art use the same rule.

`UI-TargetingFrame.blp` and `UI-TargetingFrame.png` are the normal atlas. The PNG is the stripped atlas. The client loads the TGA.
